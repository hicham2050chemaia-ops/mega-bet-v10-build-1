# MEGA BET V10 BUILD 1

واجهة PWA أولية قابلة للتشغيل والنشر على استضافة HTTPS.

## المحتويات
- `index.html`: هيكل التطبيق.
- `style.css`: تصميم أسود وأخضر نيوني متجاوب.
- `app.js`: التنقل والتصفية والتثبيت.
- `manifest.json`: إعدادات PWA.
- `service-worker.js`: التخزين المؤقت والعمل عند ضعف الاتصال.
- `icon.svg`: أيقونة التطبيق.

## التشغيل
افتح المستودع على GitHub وارفع **محتويات هذا المجلد** إلى جذر المستودع. فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root). انتظر نشر الموقع ثم افتح رابط HTTPS على Android.

## مهم بخصوص البيانات
المباريات الظاهرة في هذه النسخة أمثلة تجريبية وليست مباريات حقيقية أو مباشرة. لم يتم تضمين API key أو الادعاء بوجود اتصال حي. لإضافة بيانات حقيقية يجب اختيار مزود بيانات رياضية، الحصول على مفتاح API، ثم ربطه عبر وسيط خلفي آمن وعدم وضع المفتاح السري داخل `app.js`.

## ملاحظات الجودة
- ملفات HTML وCSS وJavaScript وJSON منفصلة.
- لا توجد مكتبات خارجية إلزامية لتشغيل الوظائف الأساسية.
- يلزم HTTPS أو localhost حتى يعمل Service Worker والتثبيت.
